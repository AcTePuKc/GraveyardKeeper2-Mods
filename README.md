# Graveyard Keeper 2 — Bulgarian Mods

Community mods and Bulgarian localization for **Graveyard Keeper 2**.

## Mods

### Date Time and Counter

Source: [`mods/date-time-and-counter/`](mods/date-time-and-counter/)

A BepInEx plugin that displays the in-game day, optional clock, or both. It requires BepInEx 5.4.23.x and GK2 Mod Framework 0.1.12 or newer. See its README for installation, settings, locale files, and build instructions.

### Bulgarian localization

Game language package: [`mods/bulgarian-localization/Languages/bg/`](mods/bulgarian-localization/Languages/bg/)

The package includes `language.json`, `strings.csv`, and the Bulgarian pixel font referenced by the language definition. Copy the `Languages/bg` folder to the game's `Languages` folder, or to the per-user Mods location:

```text
%USERPROFILE%/AppData/LocalLow/Lazy Bear Games/Graveyard Keeper 2/Mods/Languages/bg/
```
